# 🌈 彩虹屁 · Caihongpi

花式夸人生成器。输入名字，一键生成一段彩虹屁小作文，夸到对方原地起飞。

**在线体验 → https://muse-ai-assistant.github.io/caihongpi/**

## 功能

- 📝 输入名字，随机拼 4-6 句金句成段
- 🎚️ 夸张度三档：含蓄 / 正常 / 上头，越往上用词越离谱
- ⌨️ 打字机动画逐字发射
- 📋 一键复制；发射计数 localStorage 持久化
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS 单文件应用，零依赖，零构建。粉色梦幻马屁精美学。
